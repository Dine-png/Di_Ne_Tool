# Di Ne Expression Editor

Expression Menu와 Expression Parameters를 **VRCSDK+ 방식의 간단한 Inspector**로 편집합니다. 설치된 VRCSDK+ 1.6.2의 화면과 동작을 기준으로 구성했으며, 큰 Di Ne 헤더나 추가 옵션 패널 없이 목록 옆 버튼으로 바로 작업합니다.

## Expression Menu

- 작은 드래그 목록에서 순서를 바꾸고, 각 항목 오른쪽 `−` 버튼으로 삭제합니다. 목록 아래 `+`로 추가합니다.
- 목록 제목 오른쪽에 복사·붙여넣기·복제·이동 버튼이 있습니다. 붙여넣기는 선택한 항목에 값 붙여넣기 또는 새 항목 삽입을 선택합니다.
- 이동 버튼을 누른 뒤 다른 메뉴로 이동하여 배치 버튼을 누르면 항목이 이동합니다. 두 메뉴의 변경은 하나의 Undo로 복구됩니다. Escape로 이동을 취소합니다.
- 선택한 항목의 이름·유형·아이콘과 색상·굵게·기울임을 목록 바로 아래에서 편집합니다. 서식은 메뉴 이름의 rich text 태그에 반영합니다.
- 파라미터는 아바타의 Expression Parameters에서 선택합니다. 없는 이름은 옆 **추가** 버튼으로 해당 에셋에 추가합니다. Puppet 축과 레이블·아이콘도 같은 화면에서 설정합니다.
- 서브메뉴는 **새로 만들기·열기·연결 해제** 버튼으로 관리합니다. 목록의 서브메뉴 항목을 두 번 클릭해 열 수도 있습니다.
- 상단의 `<<`, `<`, `>`, `>>`는 메뉴 방문 이력을 탐색합니다. 메뉴 이름을 누르면 에셋을 강조합니다.
- Inspector 메뉴의 **간결한 모드 / Compact Mode**로 아이콘과 Puppet 설정을 작게 표시할 수 있습니다.

목록 우클릭 메뉴와 Ctrl/Cmd+C·X·V·D, Delete도 지원합니다. 복제는 이름 끝 숫자, Bool 파라미터 이름 끝 숫자 또는 Int 값을 증가시킵니다. Shift를 누르면 파라미터·값 증가를 생략합니다. 메뉴당 8개 항목 한도를 지킵니다.

## Expression Parameters

- 이름·유형·기본값·Saved·Synced를 한 줄에서 편집합니다. 각 줄 오른쪽 `−`로 삭제하고 아래 `+`로 추가합니다.
- 이름 옆 드롭다운은 활성 아바타의 Animator 파라미터를 검색합니다. 컨트롤러에 없는 이름은 옆 **추가** 버튼으로 지정한 Playable Controller에 추가합니다.
- 이름 제목의 검색 버튼이나 Ctrl/Cmd+F로 검색합니다. 일치하지 않는 행은 흐리게 표시합니다.
- 빈 이름·아바타 컨트롤러에 없는 이름·중복 이름이 있을 때 **정리**가 표시됩니다. 중복은 첫 항목을 유지합니다.
- 항상 표시되는 **파라미터 병합 / Merge Parameters** 필드에 에셋을 선택하면 그 에셋의 모든 파라미터 복사본을 끝에 추가합니다. VRCSDK+와 같이 중복 이름도 포함하며, 선택 필드는 비워집니다.
- 목록 아래 **전체 메모리 / Total Memory**에 동기화 비용과 SDK 한도를 표시합니다. 한도 초과는 경고하며 편집 자체를 막지 않습니다.

폭이 좁은 Inspector에서는 표를 가로로 스크롤하여 한 줄의 필드와 버튼을 사용할 수 있습니다. 원본 VRCSDK+에서 좁은 폭에 필드가 겹치는 현상은 재현하지 않습니다.

## 아바타와 설정

**활성 아바타 / Active Avatar**는 조회할 아바타를 선택합니다. 아바타의 FX Controller·Expression Menu·Expression Parameters 및 Multi Dresser 참조를 자동 배정하거나 교체하지 않습니다. 메뉴와 파라미터 에셋 자체의 편집은 직접 저장되므로, 별도 버전이 필요하면 먼저 에셋을 복제하세요.

Avatar Descriptor의 컴포넌트 메뉴에 **[Di Ne] Quick Setup**이 있습니다. 눈·머리 위치로 View Position을 맞추고, Eye Look과 Blink, Lip Sync를 설정합니다. 이 작업도 Expression 및 FX 참조를 교체하지 않으며 Undo를 지원합니다.

문구는 공통 `DiNeLang`의 English / 한국어 / 日本語를 사용합니다. Inspector 우클릭 메뉴의 **Di Ne → 언어**에서 바꿉니다. **DiNe → Expression Editor → Di Ne Inspector**를 해제하면 공식 SDK Inspector로 돌아갑니다. 설정은 `EditorPrefs`에 저장됩니다.

VRCSDK+와 동시에 설치하면 같은 Inspector에 대한 등록이 충돌할 수 있습니다. 기존 패키지 감지 경고를 유지합니다. VRCSDK+ 소스·DLL·전용 에셋을 제품 패키지에 포함하지 않으며, Unity의 기본 아이콘과 SDK 데이터 API로 독립 구현했습니다.

## 편집과 UI 기준

목록 작업과 컨트롤러 추가는 Unity Undo·dirty 상태를 지원합니다. Inspector 조회 및 repaint는 에셋의 내용이나 아바타 참조를 변경하지 않습니다. Play Mode와 읽기 전용 에셋에서는 편집을 잠급니다. 기본 SDK 화면으로 전환할 때도 초기화에 의한 기본 파라미터 생성이나 메뉴 참조 자동 배정을 방지합니다.

[Di Ne UI Standard](DI_NE_UI_STANDARD.md)의 체크리스트를 검토했습니다. 사용자가 명시한 **“정말 VRCSDK+의 기능과 UI와 동일하게”** 요청에 따라 이 Inspector에 큰 브랜드 헤더·제목 폰트·민트 툴바·카드·화면의 언어 버튼을 적용하지 않습니다. 다른 Di Ne 도구에는 적용하지 않는 예외입니다.

- [x] 기준 도구의 작은 목록·행 옆 버튼·선택 항목 설정 배치 사용
- [x] 세 언어와 공통 `DiNeLang`, 현지화한 툴팁·경고 사용
- [x] 자주 사용하는 추가·삭제·설정을 화면에서 바로 접근
- [x] 반복되는 도구 제목·메뉴 이름·아이콘 카드 제거
- [x] Undo·dirty·Prefab override 및 조회 시 비변경 보존
- [x] Editor 에셋 Inspector에는 컴포넌트 아이콘·튜토리얼 적용 대상 없음

격리 프로젝트에서 실행하는 검증 방법과 결과 범위는 [테스트 README](../Tests/ExpressionEditor/README.md)에 있습니다. 테스트는 합성 아바타·에셋만 사용하며 사용자 아바타 프로젝트와 원본 씬 참조를 변경하지 않습니다.

2026-10-05 Unity 2022.3.22f1의 격리 프로젝트에서 최종 소스로 회귀 검사 27개와 화면 검사 126개를 통과했습니다. 기본 SDK·VRCSDK+ 방식·Compact 화면 15개를 캡처하고, 설치된 VRCSDK+ 1.6.2의 실제 화면 8개와 비교했습니다. 행 옆 삭제·추가 클릭과 Undo, 메뉴 이동, 전체 병합, 컨트롤러 추가 및 Quick Setup을 검증했습니다. 합성 아바타의 원본 참조와 전역 언어·Inspector·Compact 설정 복원을 확인했으며 사용자 프로젝트나 씬을 수정하지 않았습니다.
